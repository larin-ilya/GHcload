# Changelog — GITHUBCLOAD

Все заметные изменения по версиям. Формат: [Semantic Versioning](https://semver.org).
Даты — по факту сборки релиза.

---

## v1.3.1 — 2026-09-29

### Исправлено
- **Телеграм-бот: имя файла при заливке больше не искажается.** Раньше элемент
  сохранялся с числовым префиксом (например, `1790638691_отчёт.pdf`). Теперь файл
  принимается во временную папку с исходным именем — в облаке видно ровно то имя,
  которое было у файла.
- **Имя ZIP-архива при скачивании папки** — по имени папки (раньше было `item_<id>.zip`).
- Версия бота — 1.0.1 (видна в `/status`).

## v1.3.0 — 2026-09-29

### Добавлено
- **Телеграм-версия** — `GITHUBCLOAD_TG.py` (aiogram 3): бот принимает файлы и заливает их
  в приватное облако, ходит по хранилищам кнопками, скачивает файлы (до 50 МБ — предел Bot API
  на отправку) и удаляет элементы. При первом запуске просит пароль шифрования и токен GitHub,
  хранит их локально (`data/users/<id>/`, права 600) и запоминает пользователя.
  Загрузка по умолчанию — в хранилище `telegram`; другое хранилище задаётся командой
  `/storage имя` или меткой `#имя` в подписи к файлу. Ограничение приёма — 20 МБ
  (предел Bot API `getFile`).
- `requirements-tg.txt` — зависимости телеграм-версии (py7zr, PyGithub, aiogram).
- `deploy/gcb-telegram.service` — пример unit-файла systemd для автозапуска бота.

## v1.2.1 — 2026-09-28

Полировка внешнего вида Windows-GUI (функциональность не менялась).

### Изменено
- **Журнал:** перенос строк по словам — длинные имена (`LEGAL.md`) больше не разрываются
  посередине; высота панели журнала увеличена (136 → 156 px).
- **Контраст:** вторичный текст и подписи стали заметно темнее (читаемость на светлом
  фоне), статус подключения — насыщеннее зелёный/красный.
- **Заголовки томов** в списке файлов — мягкая акцентная плашка вместо серого inset.
- **Сводка по хранилищу** («Томов: N · элементов: M · занято: S») перенесена в строку
  над списком: раньше она накладывалась на первую строку.
- **Ряд кнопок** вверху растягивается на всю ширину (промежутки распределяются),
  подписи не обрезаются.
- **Поля ввода** получили внутренние отступы — текст больше не «прилипает» к рамке.
- **Страница «Самопроверка»:** карточка диагностики подогнана по содержимому,
  увеличены отступы информационной карточки, кнопка «Правовая информация» выровнена
  с заголовком.
- **Вкладка «Загрузка»:** строка сведений о пути показывается только когда путь выбран,
  и вынесена под колонку кнопок — правая колонка больше не «разъезжается».
- **Активная вкладка** в сайдбаре получила акцентную полосу слева.
- **Карточка «Статус подключения»** сжата по содержимому и выровнена по низу с журналом.
- **Подписи кнопок** больше не переносятся на вторую строку: размер шрифта подбирается
  под ширину кнопки (например, «Удалить выбранные» в ряду из пяти кнопок).
- **Журнал** при автопрокрутке выравнивается по целым строкам — верхняя строка больше
  не обрезается наполовину.
- **Кнопки «Скачать»/«Удалить»** в строке файла отодвинуты от края карточки, тень мягче.

## v1.2.0 — 2026-09-27

Паритет Windows-GUI с Linux-GUI: нативный интерфейс (Win32 + GDI+) догоняет
tkinter-версию по функциям.

### Добавлено (Windows-GUI, `GCB_GUI.cpp`)
- **Правовое предупреждение при запуске** — одна короткая строка (лицензия, «как есть»,
  ссылки на `LEGAL.md`/`LICENSE`) выводится в консоль и в журнал, ровно один раз за запуск.
- **Подтверждение условий использования** (clickwrap) при первом запуске: окно с
  прокручиваемым текстом, согласие сохраняется в `_gcb_terms.json` рядом с программой
  (атомарная запись, версия условий 1.0); отказ или закрытие окна — выход с кодом 3.
- **Окно «Правовая информация»** на странице «Самопроверка»: краткая справка и кнопки
  открытия `LEGAL.md` / `LICENSE` (сначала локальный файл рядом с программой, иначе —
  ссылка в репозитории проекта; при неудаче ссылка копируется в буфер обмена).
- **Блок «Диагностика»** на странице «Самопроверка»: папка приложения, статус принятия
  условий, выбранный движок, наличие `tokengh.txt` / `PBEpass.txt`, версия GUI.
- **Служебные флаги командной строки:** `--version` (версия, код 0), `--help` (справка,
  код 0), `--smoke` (сборка окна и всех трёх страниц без показа, код 0),
  `--accept-terms` (принять условия без диалога); неизвестные аргументы — код 2.
- **Полноценный журнал вместо консоли последней команды:** строки накапливаются и
  подсвечиваются по типу (команда / ошибка / предупреждение / успех), кнопка «Очистить»,
  переключатель «Автопрокрутка», ограничение 5000 строк, подпись текущего действия и
  код возврата каждой операции.
- **Сведения о выбранном пути** на вкладке «Загрузка»: размер файла либо число файлов и
  суммарный размер папки (подсчёт в фоне, окно не замирает); пояснение о шифровании.
- **Группировка содержимого хранилища по томам:** заголовки «ТОМ <имя> (занято X из ~Y)»
  и сводка «Томов: N · элементов: M · занято: S».
- **Удаление элементов:** кнопка «Удалить» в строке элемента и «Удалить выбранные» по
  галочкам (последовательно, по одному id) — с подтверждением.

### Изменено
- Версия GUI поднята до 1.2.0 синхронно в Windows- и Linux-интерфейсах
  (`GCB_GUI.cpp` и `GITHUBCLOAD_GUI.py`).

## v1.1.0 — 2026-09-15

### Добавлено
- **Графический интерфейс для Linux** — `GITHUBCLOAD_GUI.py` на tkinter (Linux-first):
  разделы «Хранилища» / «Загрузка» / «Самопроверка» + общий журнал; двойной клик по
  хранилищу открывает содержимое; удаление и wipe — с подтверждением. Возможности
  повторяют Windows-версию, форматы архивов полностью совместимы.
- **Сборка единого самодостаточного Linux-бинарника** `dist/GITHUBCLOAD_GUI`
  (PyInstaller --onefile, движок вшит): `build_gui_linux.sh` и воспроизводимая
  сборка в Docker `build_linux_docker.sh` (python:3.11-slim-bookworm).
- `run_gui_linux.sh` — запуск из исходников с автосозданием venv; системный
  пакет `python3-tk` проверяется с понятной ошибкой.
- Служебные флаги GUI: `--version`, `--smoke` (headless-проверка под Xvfb),
  `--accept-terms`, `--help`.
- Скриншоты Linux-интерфейса (`screenshots/linux_gui_preview.png` и окно подтверждения
  условий `screenshots/linux_terms_preview.png`) и раздел README «Графический интерфейс
  в Linux».
- **Иконка приложения:** `app.png` (PNG 256×256, получена из `app.ico` через Pillow) —
  иконка окна и всех диалогов; кладётся внутрь единого бинарника (`_MEIPASS`), сборка
  дополнительно получает `--icon app.ico` (для платформ, где он используется).
- **Интеграция в меню Linux:** `GITHUBCLOAD_GUI.desktop` (`Icon=app`,
  `Categories=Utility;FileTools;`) с пояснением по установке в README.
- **Правовое предупреждение при запуске:** одна короткая строка (лицензия, «как есть»,
  ссылки на `LEGAL.md`/`LICENSE`) выводится в консоль (stderr) и в журнал GUI, не
  дублируется при операциях; `--smoke` печатает в stdout путь найденной иконки.
- **Правовые документы:** `LICENSE` (GNU AGPL-3.0-or-later, с возможностью отдельной
  коммерческой лицензии) и `LEGAL.md` — допустимое использование, отказ от гарантий,
  предупреждения о нешифруемых метаданных и правилах GitHub.
- **Подтверждение условий при первом запуске GUI** (сохраняется в `_gcb_terms.json` рядом
  с программой) и раздел «Правовая информация» в интерфейсе.

## v1.0.0 — 2026-09-07

Первый оформленный релиз. Приватное «облачное» хранилище поверх GitHub:
шифрование 7z (AES-256), разрезка на части по 8 МБ, приватные репозитории-тома.

### Добавлено
- **Вкладка «Хранилища»** — список хранилищ, двойной клик открывает том со списком
  файлов и чекбоксами; «Скачать выбранные», «Скачать всё», «Удалить» (по id), «Стереть» (wipe).
- **Вкладка «Загрузка»** — поля для пути и имени хранилища, кнопки «Выбрать файл»/
  «Выбрать папку», кнопка «Загрузить в облако».
- **Вкладка «Самопроверка»** — selftest без GitHub (7z + AES-256 + мультитом).
- **Drag-and-drop** файла/папки прямо в окно: автоматически переключает на «Загрузку»
  и подставляет путь.
- **Выпадающий список имён хранилищ** — кнопка «▾» у поля хранилища: раскрывает
  список существующих томов, клик подставляет имя.
- **Кастомная иконка приложения** — сгенерирована (jankrouter, SDXL-lightning),
  вшита в exe ресурсом `1 ICON`, применена к окну.
- Нижняя **консоль** вывода команд движка + панель статуса токена/пароля.

### Изменено / улучшено (визуальный редизайн)
- Убран дубль подсказки внутри хранилища: инструкция показывается один раз в заголовке
  («клик по строке…» либо «отмечено файлов: N»).
- Тени неоморфизма приведены к аккуратным: ограничен радиус размытия (макс. 6 px),
  снижена интенсивность — убрана «смазанность», границы кнопок/карточек читаются.
- Акцентные (синие) кнопки получили внутренний светлый блик сверху — объём без плоского
  drop-shadow.
- Поля ввода и консоль теперь настоящие **inset** (внутренние тени с клипом), а не
  «плавающие» карточки с внешней тенью снизу.
- Панель статуса компактнее, строки «Токен / Пароль» с равными интервалами.
- Консоль ниже (не доминирует над экраном).
- Логотип: умеренное свечение, читаемая подпись «приватное облако».
- Пустое состояние оформлено центрированной карточкой с иконкой-облаком вместо голой строки.
- Иконка окна загружается из ресурса (не системная).

### Исправлено
- Кнопка «Загрузить в облако» больше не перекрывает раскрытый список хранилищ
  (список рисуется поверх — как обычное меню).
- Стрелка «▾» у поля хранилища больше не выглядит обрезанной (рисуется как чёткий
  треугольник; placeholder не перекрывает её).
- Имя/метка файлов не переносятся и не заезжают на id в карточках (однострочное
  многоточие).
- Чекбоксы с акцентной рамкой — контрастнее.
- Исправлен дефект вёрстки: кнопка «Выбрать папку» больше не наезжает на поле хранилища.

### Сборка
- Единый файл `GITHUBCLOAD_GUI.exe` (GUI + движок PyInstaller внутри).
- См. `README.md` → «Сборка».
